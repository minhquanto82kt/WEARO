# Basic — Color Palette

**Phạm vi:** trang collection Basic.

| Vai trò | HEX |
|---|---|
| Primary — màu chính | `#252525` |
| Secondary — màu phụ | `#777771` |
| Accent — màu nhấn | `#D8D5CE` |
| Paper — nền trang | `#F5F3EF` |
| Ink — chữ mặc định | `#171717` |

## CSS variables

```scss
--collection-ink: #171717;
--collection-primary: #252525;
--collection-secondary: #777771;
--collection-accent: #D8D5CE;
--collection-paper: #F5F3EF;
```

Nguồn: `src/styles/wearo-collection-pages.scss`, selector `.wearo-collection-page[data-collection="basic"]`.

**Lưu ý:** Đây là palette của trang collection Basic; chưa xác nhận là màu nền của thẻ Basic trên trang chủ.
