# Outing Style — Color Palette

**Phạm vi:** trang collection Outing Style.

| Vai trò | HEX |
|---|---|
| Primary — màu chính | `#355C4A` |
| Secondary — màu phụ | `#8EAD91` |
| Accent — màu nhấn | `#E7B879` |
| Paper — nền trang | `#F2F4ED` |
| Ink — chữ mặc định | `#171717` |

## CSS variables

```scss
--collection-ink: #171717;
--collection-primary: #355C4A;
--collection-secondary: #8EAD91;
--collection-accent: #E7B879;
--collection-paper: #F2F4ED;
```

Nguồn: `src/styles/wearo-collection-pages.scss`, selector `.wearo-collection-page[data-collection="outing-style"]`.

**Lưu ý:** Đây là palette của trang collection Outing Style; chưa xác nhận là màu nền của thẻ Outing Style trên trang chủ.
